# RetailPulse Dataset Overview

## Dataset Name
Brazilian E-Commerce Public Dataset by Olist

## Source
Kaggle

## Description
Real-world anonymized Brazilian e-commerce
data containing orders, customers, products,
payments, sellers and reviews.

## Data Format
CSV

## Number of Files
9

## Time Period
2016 - 2018

## Data Location
data/raw/

## Dataset Tables

1. Customers
2. Orders
3. Order Items
4. Order Payments
5. Order Reviews
6. Products
7. Sellers
8. Geolocation
9. Category Translation
